# AxData 全面分析报告（08-11 自行维护）

> 方法：codebase-memory 架构视图 + 4 路并行深度研究 + 实测验证
> 结论：架构成熟（自研 TDX wire + 插件体系 + 1227 测试），确认 3 个高优先 bug + 8 个中低优先项，2 个静态推测被实测否定

## 一、架构总览

```
apps/api (FastAPI)      — 10 路由（source/plugin/query/data/downloader/collector/calendar/tdx-server/auth/stream）
apps/web (React)        — 数据浏览/采集/下载控制台
libs/axdata_core        — 请求分发/插件注册/下载器/采集调度/存储查询/日历缓存/TDX wire 兼容层
packages/axdata-sdk     — Client（local 直连 / api HTTP 双路径）
packages/axdata-source-*— 5 数据源插件（tdx 最大 / tdx-ext / cninfo / tencent）
services/              — collector 采集服务 + worker 工作进程
tests/                 — 49 文件 1227 用例（tdx adapter 241 + provider 172 最充分）
```

**请求链路**：`Client.call → request_interface → registry 解析 adapter → provider（source 插件）→ 归一化 → 字段投影`

**TDX 链路**：`TdxRequestAdapter → request_dispatch → request_methods → 域 fetch → _tdx_wire（自研 7709 协议：socket 超时 8s/心跳/重连/池）→ 归一化`

## 四、设计观察（记录，暂不修）

- F10 topic lookup 无显式超时（client 8s 兜底）
- heartbeat 失败杀全部在途请求（默认关闭 dormant）
- 多处 `except Exception` 过宽（price_decimal 等）——调试难度
- 日期归一化静默 None（7 位日期）——缺警告
- DuckDB 缺失字段静默 NULL——schema 漂移不可见
- 日历刷新/插件配置写并发无锁（MVP 可接受）
- 测试盲区：services/worker 全部、csv_adapter、官方交易所 XLSX 解析、quality.py

## 五、修复优先级建议

1. HIGH: builtin_providers 动态日期（2027 前必修）
2. MED: wire BSE 分类 + ETF sh52（代码一致性）
3. MED: stream_router 鉴权统一（安全）
4. MED: scheduler 日志 + downloader 锁（健壮性）
5. LOW: SDK cache 导出 / 心跳 / worker limit（SDK 质量）
